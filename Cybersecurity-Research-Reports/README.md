#  What is Cyber Security?

Cyber Security is the practice of protecting computers, mobile devices, networks, applications, and digital information from unauthorized access, cyber attacks, theft, or damage.

Its primary goal is to ensure:

- Confidentiality
- Integrity
- Availability (CIA Triad)

---

# Why is Cyber Security Important?

In today's digital world, people use the internet for:

- Online Banking
- Social Media
- Shopping
- Education
- Healthcare
- Business

Without proper security measures, attackers can steal:

- Passwords
- Personal Information
- Financial Data
- Photos
- Emails
- Business Data

Cyber Security helps protect users from cyber threats and ensures privacy and secure online communication.

#  Common Cyber Threats

## 1. Phishing

Phishing is a social engineering attack where attackers send fake emails, messages, or websites to trick users into revealing sensitive information.

### Examples

- Fake Bank Email
- Fake Microsoft Login
- Fake Facebook Login
- Prize Scam

---

## 2. Malware

Malware is malicious software designed to:

- Damage systems
- Steal information
- Encrypt files
- Spy on users

Common malware includes:

- Virus
- Worm
- Trojan
- Spyware
- Ransomware

---

## 3. Weak Passwords

Weak passwords are easy to guess using:

- Dictionary attacks
- Brute-force attacks
- Password spraying

Examples:

? 123456

? password

? admin123

---

## 4. Fake Websites

Cybercriminals create websites that look identical to legitimate websites in order to steal:

- Username
- Password
- Credit Card Information
- Banking Credentials

---

## 5. Data Leaks

A data leak occurs when sensitive information is exposed to unauthorized users.

Examples include:

- Customer Records
- Employee Information
- Password Databases
- Financial Data

---

#  Password Security

A strong password should:

- Be at least 12 characters long
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters

### Example

```
T@lha2026!Secure
```

### Password Best Practices

- Use unique passwords
- Never reuse passwords
- Use a password manager
- Enable Multi-Factor Authentication (MFA)

---

# Phishing Awareness

Phishing attacks trick users into revealing sensitive information by pretending to be trusted organizations.

## Common Phishing Techniques

- Fake Emails
- Fake Login Pages
- SMS Phishing (Smishing)
- Voice Phishing (Vishing)
- Social Media Messages

---

## How to Identify Phishing

- Check sender email

- Verify URLs

- Avoid urgent messages

- Look for spelling mistakes

- Never enter credentials on unknown websites

---

#  Ransomware

Ransomware is malware that encrypts files or systems and demands payment to restore access.

## Common Infection Methods

- Phishing Emails
- Malicious Attachments
- Software Vulnerabilities
- Weak RDP Passwords
- Infected Downloads

---

## Impact of Ransomware

- File Encryption
- Financial Loss
- Operational Downtime
- Data Theft
- Reputational Damage

---

#  Cyber Safety Best Practices

## 1. Use Strong Passwords

Create long and complex passwords using letters, numbers, and symbols.

---

## 2. Enable Multi-Factor Authentication

Use MFA whenever available for an additional layer of security.

---

## 3. Avoid Unknown Links

Never click suspicious links received through emails, SMS, or social media.

---

## 4. Verify URLs

Use services like:

- VirusTotal

to check suspicious links before opening them.

---

## 5. Keep Software Updated

Install operating system and application updates regularly to patch security vulnerabilities.

---

## 6. Install Antivirus

Use reputable antivirus and endpoint protection software.

---

## 7. Backup Important Data

Maintain secure offline and cloud backups to recover from ransomware attacks.

---

## 8. Secure Wi-Fi Networks

Use strong Wi-Fi passwords and WPA2/WPA3 encryption.
