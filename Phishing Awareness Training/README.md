# 📖 Project Overview

The **Phishing Email Analysis & Security Awareness** project demonstrates a structured investigation of a suspicious email using industry-standard email security techniques and open-source threat intelligence tools.

The objective was to identify phishing indicators, validate sender authenticity, analyze email headers, inspect embedded URLs and attachments, extract Indicators of Compromise (IOCs), and document the investigation using a Security Operations Center (SOC) methodology.

In addition to the technical investigation, a complete awareness walkthrough was created to demonstrate how phishing attacks operate and how users can recognize and avoid them.

This project reflects the practical workflow commonly followed by **SOC Analysts, Blue Team Analysts, Incident Responders, and Email Security Analysts** when investigating suspected phishing campaigns.

# 🔍 Investigation Phases

## 📧 Email Examination

Initial inspection focused on identifying suspicious characteristics such as:

- Sender identity
- Subject line
- Social engineering techniques
- Urgent language
- Suspicious formatting

---

## 📨 Email Header Analysis

The email headers were analyzed to validate:

- Sender IP Address
- Return Path
- SPF Validation
- DKIM Verification
- DMARC Policy
- Message Routing

---

## 👤 Sender Verification

The sender's domain was investigated by reviewing:

- Domain Reputation
- WHOIS Records
- Domain Registration Details
- Domain Age
- Email Authenticity

---

## 🔗 URL Investigation

Embedded URLs were extracted and validated using multiple threat intelligence sources.

The analysis included:

- URL Reputation
- Safe Browsing Checks
- Redirect Analysis
- Typosquatting Detection
- Fake Login Pages
- Shortened URLs

---

## 📎 Attachment Analysis

Suspicious attachments were investigated by reviewing:

- File Extension
- File Hash
- VirusTotal Detection Results
- Embedded Macros
- Executable Content
- File Reputation

---

## 🌐 Threat Intelligence

Indicators of Compromise (IOCs) were validated using open-source intelligence platforms.

Examples included:

- Malicious Domains
- Suspicious URLs
- IP Addresses
- File Hashes
- Reputation Scores

# 🚩 Phishing Indicators Identified

During the investigation, multiple phishing characteristics were identified:

- Suspicious Sender Address
- Domain Spoofing
- Urgent Call-to-Action
- Fake Login Pages
- URL Mismatch
- Social Engineering Tactics
- Suspicious Attachments
- Credential Harvesting Indicators

---

# 🛡️ Security Awareness Recommendations

To reduce phishing risks, the following best practices are recommended:

- Verify sender identity before responding
- Inspect URLs before clicking
- Never submit credentials through unknown links
- Scan attachments before opening
- Enable Multi-Factor Authentication (MFA)
- Report suspicious emails immediately
- Keep systems and antivirus software updated
- Participate in regular security awareness training
