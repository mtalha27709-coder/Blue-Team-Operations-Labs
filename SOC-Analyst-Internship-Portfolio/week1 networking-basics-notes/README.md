# Week 1 - Setup & Networking Fundamentals

## Objective
The objective of this week was to set up essential cybersecurity tools and understand basic networking concepts required for network security and traffic analysis.

## Tools Installed
- Wireshark (Packet Analysis)
- Cisco Packet Tracer (Network Simulation)
- Notepad++ / VS Code (Documentation)

## Tasks Completed
- Installed and configured required tools
- Learned basic networking fundamentals
- Created simple network topology in Packet Tracer
- Verified connectivity using ICMP (ping)

## Key Learning Areas
- IP Addressing (IPv4 / IPv6)
- TCP vs UDP protocols
- DNS, HTTP, ICMP basics
- Network device roles (Router, Switch, PC)

## Outcome
Successfully completed foundational setup required for Network Traffic Analysis and Security Labs in upcoming weeks.
