# Networking Basics Notes

## 1. IP Address
An IP address is a unique identifier assigned to each device on a network.

Types:
- IPv4 (e.g., 192.168.1.1)
- IPv6 (longer format, modern standard)

---

## 2. TCP (Transmission Control Protocol)
- Connection-oriented protocol
- Reliable data delivery
- Used in web browsing, emails

---

## 3. UDP (User Datagram Protocol)
- Connectionless protocol
- Faster but less reliable
- Used in streaming, gaming

---

## 4. DNS (Domain Name System)
- Converts domain names into IP addresses
- Example: google.com ? IP address

---

## 5. ICMP (Internet Control Message Protocol)
- Used for network diagnostics
- Example: ping command

---

## 6. Network Devices

### Router
Connects different networks

### Switch
Connects devices within same network

### PC
End device used for communication
