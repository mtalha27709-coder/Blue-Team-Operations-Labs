# Attack Scenarios

## Scenario 1: Brute Force Attack
Multiple failed login attempts from single IP targeting admin account.

---

## Scenario 2: Credential Compromise
Successful login after repeated failed attempts.

---

## Scenario 3: PowerShell Malware Execution
Encoded PowerShell commands used to hide malicious activity.

---

## Scenario 4: Data Exfiltration Attempt
PowerShell used to download external files using Invoke-WebRequest.
