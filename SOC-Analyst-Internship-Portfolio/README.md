# 📖 Project Overview

The **Enterprise SOC Analyst Internship Portfolio** represents the successful completion of a six-week hands-on Security Operations Center (SOC) internship focused on enterprise security monitoring, network traffic analysis, threat detection, SIEM operations, and incident investigation.

Throughout this internship, practical experience was gained by working with real-world cybersecurity tools including **Splunk Enterprise**, **Wireshark**, **Windows Event Logs**, and **PowerShell** while following industry-standard SOC methodologies.

The portfolio documents the complete learning journey from networking fundamentals to advanced SIEM investigations, log correlation, threat hunting, and professional security reporting.

Each weekly project builds practical skills commonly required by **SOC Analysts, Blue Team Professionals, Detection Engineers, Incident Responders, and Cybersecurity Analysts** working in modern enterprise environments.
