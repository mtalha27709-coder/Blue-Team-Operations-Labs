# Network Traffic Analyzer (Wireshark) - Final Submission

## Project Overview
This project focuses on analyzing network traffic using Wireshark to detect normal and suspicious network behavior.

## Project Type
Network Traffic Analysis / Security Monitoring

## Tools Used
- Wireshark
- VirusTotal (Threat Intelligence)

## Key Activities
- Captured live network traffic
- Analyzed DNS, TCP, and HTTP protocols
- Investigated suspicious traffic patterns
- Verified domains and IPs using VirusTotal
- Followed TCP streams for deep inspection

## Outcome
Completed a full network traffic analysis workflow with security-focused investigation.
