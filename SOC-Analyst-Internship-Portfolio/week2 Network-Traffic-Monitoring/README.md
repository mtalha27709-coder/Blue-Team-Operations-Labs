# Network Traffic Analyzer using Wireshark

## Objective
The objective of this project was to capture, analyze, and investigate live network traffic using Wireshark in order to understand network protocols and identify suspicious activity.

## Tool Used
- Wireshark (Primary Tool)

## Methodology
- Captured live network traffic using Wireshark
- Applied multiple filters for protocol analysis
- Investigated DNS, TCP, and general traffic behavior
- Followed suspicious traffic streams for deeper inspection
- Verified suspicious IPs and domains using VirusTotal
- Documented findings with screenshots

## Filters and Analysis Performed
- DNS Traffic Analysis
- TCP Traffic Analysis
- TCP Stream Follow
- TCP Endpoints Analysis
- TCP Top Talkers (Top Endpoints)
- HTTP / General Packet Inspection

## Suspicious Activity Investigation
The following checks were performed:
- Suspicious DNS queries identified and analyzed
- DNS domains checked on VirusTotal
- Suspicious TCP connections investigated
- TCP streams followed for detailed packet inspection
- TCP endpoints analyzed for unusual communication patterns
- Top TCP endpoints reviewed for abnormal traffic spikes

## Screenshots Captured
- Main Wireshark capture window
- DNS traffic filtering view
- TCP endpoints statistics
- TCP top conversations
- TCP stream follow analysis
- Suspicious DNS and TCP investigation results (VirusTotal checks)

## Outcome
Successfully analyzed real-time network traffic and identified potentially suspicious DNS and TCP behavior using Wireshark and external threat intelligence (VirusTotal).
