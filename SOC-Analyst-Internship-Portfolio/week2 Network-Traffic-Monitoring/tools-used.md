# Tools Used

## 1. Wireshark
Wireshark was used as the primary tool for network traffic capture and analysis.

### Features Used:
- Packet capture
- Protocol filtering (DNS, TCP)
- Stream follow analysis
- Endpoint analysis
- Top conversations/statistics

---

## 2. VirusTotal
VirusTotal was used for external threat intelligence verification.

### Usage:
- Checked suspicious DNS domains
- Verified suspicious IP addresses
- Helped classify traffic as safe or potentially malicious

---

## Summary
Wireshark provided packet-level visibility, while VirusTotal provided external threat validation for better security analysis.
