# Log Sources

## 1. Authentication Logs
Used to detect:
- Failed login attempts
- Successful logins
- Brute-force attacks

---

## 2. PowerShell Logs
Used to detect:
- Encoded commands
- Execution policy bypass
- Suspicious scripts
- Malicious downloads

---

## 3. System Logs
Used to track:
- Process execution
- User activity
- System-level changes

---

## 4. Security Events
Used for:
- Event correlation
- Attack pattern detection
