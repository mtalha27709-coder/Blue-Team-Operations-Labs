# SIEM Log Analysis Project

## Objective
The objective of this project is to analyze security logs using SIEM concepts to detect suspicious activities such as brute-force attacks and malicious PowerShell execution.

---

## Tools Used
- Splunk (Conceptual / Simulation)
- CSV Log Dataset
- Log Analysis Techniques

---

## Key Security Areas
- Authentication log analysis
- Brute-force detection
- Suspicious PowerShell activity detection
- Pattern-based threat hunting
- Event correlation

---

## Techniques Used
- SPL queries
- Filtering logs
- Statistical analysis (stats, timechart)
- Threshold-based detection
- IOC identification

---

## Outcome
Successfully identified suspicious patterns in logs including brute-force attempts and malicious PowerShell activity using SIEM-based analysis techniques.
